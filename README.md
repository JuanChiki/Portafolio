# Portafolio de Juan David Rojas Villegas

Página web personal con estética de arte ASCII. Hecha con HTML y CSS, sin librerías ni JavaScript.

## Archivos

- `index.html`: contenido de la página
- `style.css`: estilos (los colores están al inicio, en `:root`)

## Cómo verla en tu computador

Abre `index.html` en el navegador.

## Cómo publicarla con GitHub Pages

1. Crea un repositorio público llamado `JuanChiki.github.io`.
2. Sube estos archivos a la raíz del repositorio.
3. En el repositorio ve a **Settings → Pages**, elige la rama `main` y la carpeta `/ (root)`, y guarda.
4. En un par de minutos estará en `https://juanchiki.github.io`.
